TCF v2.0 CMP Stub - postMessage PoC

Analysis Summary

This PoC targets the Amazon PRIVCONAssets-stub (11J1WJh9jNL.js). KEY FINDING: The stub initializes an origin allowlist as an EMPTY array ([]). Every postMessage is checked against this allowlist via: if (-1 === d.indexOf(e.origin)) return void b(a, "ccJsPostMessageRequestUnauthorized", 1) Since the array is never populated in the stub, ALL cross-origin messages are REJECTED. The wildcard postMessage(c, "*") response path is UNREACHABLE dead code in the stub. The full CMP (loaded later) presumably populates this allowlist and may expose the wildcard postMessage vulnerability with actual consent data (TC strings, etc.). This PoC demonstrates the TCF protocol and what WOULD be disclosed if the allowlist were populated or if the origin check were bypassed.
